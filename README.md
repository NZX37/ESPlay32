# ESPlay32

## Introduction

### What it is:

A small game console powered by seeed studio xiao esp32 c3, using an accelerometer(which offers a lot of interesting ideas), a tft display and joystick module, which features built in buzzer, battery slots and power switch and LED.

### How to use:

Using the pinouts in the schematic, you can upload code easily via arduino IDE. A few sample games will be made available soon.

The BOM provides links to the screen, joystick and accelerometer.

### Why make?

This started as a small game console i made WAY BACK(when i did my first CAD case!!) on a perfboard with a small OLED and buttons. I was hoping to upgrade it to a joystick and TFT, add an acceleromter(for cool mechanics), as well as use a PCB, buzzer and make use of the esp32's capabilities.
